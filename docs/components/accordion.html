HTML + CSS

A few good questions

Does this need an installation?

No. Paste the complete block into an HTML page. Its styles travel with it, and the browser handles opening and closing each answer.

Can I make it feel like my website?

Absolutely. Edit the text and the CSS custom properties on this block. Keep text contrast strong and try the result on a narrow screen.

Can more than one answer stay open?

Yes. Each disclosure works independently, so readers can compare answers without repeatedly opening and closing them.

Make it yours

Edit the questions and answers. Each disclosure is independent, so repeated snippets do not close one another.

Paste the complete outer element, including its first <style> child. The snippet has its own colors, spacing, type, and focus styles; it does not need this documentation site’s stylesheet.

Customize supported --bui-* variables on the outer element. Adjust the heading level to fit your document, and replace example links before publishing.

Read the embedding notes for editor support, CSS policies, nested components, and browser fallbacks.
