Make it yours

Replace the caption, column headings, and cells. The scrollable region keeps a wide table within a narrow article.

Paste the complete outer element, including its first <style> child. The snippet has its own colors, spacing, type, and focus styles; it does not need this documentation site’s stylesheet.

Customize supported --bui-* variables on the outer element. Adjust the heading level to fit your document, and replace example links before publishing.
